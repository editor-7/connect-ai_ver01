API 키와 채널 ID 설정은 자동화 파이프라인의 가장 근본적인 인프라 문제입니다. 어떤 스크립트든 코드가 아무리 완벽해도, 외부 서비스와의 인증(Authentication)이 깨지면 실행 자체가 불가능합니다. ⚙️

현재 로그와 메모리를 검토한 결과, `Researcher`와 제가 작성한 모든 자동화 스크립트가 이 크리덴셜(Credentials)에 의존하고 있습니다. 이 설정을 최우선 순위로 처리해야 합니다.

**[진행 계획]**
1.  **보안 설정:** API 키와 채널 ID와 같은 민감 정보는 코드 내에 하드코딩하는 것은 절대 금지입니다. `.env` 파일을 사용해 환경 변수로 관리하는 것이 가장 안전합니다.
2.  **코드 수정:** 이 환경 변수를 읽어 사용할 수 있도록, 기존에 작성된 자동화 스크립트들(특히 `sessions/2026-05-15T22-49` 관련 스크립트)을 수정해야 합니다.

일단, 이 설정을 위한 환경 변수 파일을 먼저 생성하겠습니다. 사용하시는 운영체제와 프로젝트 구조를 고려하여 `.env` 파일을 프로젝트 루트 디렉토리(`~/`)에 생성하겠습니다.

<create_file path="~/.env">
# =================================================================
# 🔑 YouTube API Credentials (REQUIRED)
# 이 파일은 .gitignore에 반드시 추가해야 합니다.
# =================================================================

# YouTube Data API v3 Key
YOUTUBE_API_KEY="YOUR_API_KEY_HERE"

# YouTube Channel ID (채널의 고유 식별자)
YOUTUBE_CHANNEL_ID="YOUR_CHANNEL_ID_HERE"

# (필요하다면) 비디오 업로드 전용 인증 토큰 등 추가 가능
# YOUTUBE_UPLOAD_TOKEN="YOUR_UPLOAD_TOKEN"
</create_file>

이제 이 환경 변수를 로드하여 사용할 수 있도록, 핵심 자동화 스크립트 중 하나인 `trend_sniper.py`가 위치했을 법한 가상의 경로에 환경 변수를 로드하는 초기화 로직을 추가하겠습니다. (만약 실제 스크립트 위치를 알려주시면 해당 파일을 수정하겠습니다. 일단 예시로 가정합니다.)

**만약 실제 스크립트 경로를 알려주시면, 해당 스크립트의 맨 위 부분에 `dotenv` 라이브러리를 사용하여 환경 변수를 로드하는 코드를 추가하겠습니다.**

현재는 사용자가 API 키와 채널 ID를 제공해 주셔야 다음 단계로 넘어갈 수 있습니다. 키를 제공해 주시면, 이 `.env` 파일을 기반으로 모든 관련 스크립트가 정상 작동하는지 검증하겠습니다.
